# YouTube Proxy - SA-MP

Proxy para tocar músicas do YouTube no SA-MP via PlayAudioStreamForPlayer.

## Rotas disponíveis

- `GET /play/<video_id>` — Redireciona para o stream de áudio do vídeo
- `GET /buscar/<termo>` — Retorna até 5 resultados de busca em JSON

## Exemplos

```
https://seu-app.railway.app/play/dQw4w9WgXcQ
https://seu-app.railway.app/buscar/mc ryan sp
```
